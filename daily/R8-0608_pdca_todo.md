### アイデア①：「AI補助金診断 → 申請書ドラフト自動生成」月額サブスク

**仕組み**：
- COO が補助金要件データベースを整備 → CTO が Claude API で診断フォームを構築
- 顧客がフォームに業種・売上・人数・課題を入力 → 最適補助金を自動診断 → 申請書ドラフトを Claude が生成
- LP は CMO が自動公開。申込から納品まで社長ゼロ介入

**顧客導線**：SNS広告（自動運用） → LP → フォーム申込 → 自動ドラフト納品 → サポートプランへアップセル

**想定MRR**：
- 単発プラン：5万円/件 × 月8件 = 40万円
- 月額サポート：1.5万円/月 × 20社 = 30万円
- **合計 MRR：70万円（達成後）**

**立ち上げアクション**：
1. COO：IT導入補助金・ものづくり補助金・持続化補助金の要件をデータ化（6/12まで）
2. CTO：Claude API + Google フォームで診断MVP構築（6/15まで）
3. CMO：「AI補助金診断 無料お試し」LP を Vercel で公開（6/19まで）
4. CMO：愛知県内中小企業向けに LINE・DM で初回20社に告知（6/22まで）
5. COO：申請書テンプレートの品質チェック体制を整備（6/26まで）

**必要な初期投資**：約3万円（Claude API 費用 + ドメイン + Vercel）

### アイデア②：「陰陽師 AI 鑑定 LINE Bot」リピーター自動獲得

**仕組み**：
- CTO が Claude API + LINE Messaging API で LINE Bot を構築
- 生年月日・悩みを入力 → 陰陽師的観点の鑑定文を AI が生成 → 3問まで無料 → 有料にアップセル
- CMO が LINE 配信で月2回「今月の運勢」を自動送信。社長の接触ゼロ

**顧客導線**：既存 SNS フォロワー → LINE 登録 → 無料鑑定体験 → 有料鑑定（1,500円〜）→ 月額会員（3,000円/月）

**想定MRR**：
- 有料鑑定：LINE 300人 × 転換率 5% × 1,500円 = 22,500円（初月）
- 月額会員：50人 × 3,000円 = 15万円（3ヶ月後）
- **MRR：17.2万円（3ヶ月後目標）**

**立ち上げアクション**：
1. CTO：LINE Bot + Claude API の接続実装（1週間・帰国後着手）
2. CPO：陰陽師鑑定のプロンプト設計（精度チェックは社長が1時間）
3. CMO：LINE 登録促進 SNS 投稿を3本スケジュール配信
4. COO：有料決済フロー（Stripe）の組み込み
5. CTO：月2回の自動配信スケジュールを設定

**必要な初期投資**：約2万円（Claude API + LINE API 費用）
