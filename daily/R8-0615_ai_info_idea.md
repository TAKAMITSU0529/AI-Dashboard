### 1. Anthropic「Claude Fable 5」輸出規制で突然アクセス停止→戦略的対応が急務

**要約**
6月9日に一般公開されたばかりの Claude Fable 5（旧称 Claude Mythos）が、6月12日に米国政府の輸出規制指令を受けてアクセス停止処分に。Claude Mythos 5も同様にブロック。Anthropic は「政府指令に従う義務がある」と声明を出し、現時点でどの国が対象かは非公開。一方で Claude Code は機能強化が継続中で、入れ子サブエージェント・新プラグイン検索・Chrome/VSCode統合が追加された。

**重要性**
- **AI研修**：「どのモデルが使えるか」がリアルタイムで変わる時代。研修コンテンツにモデル比較・代替モデル判断フローを追加すると差別化になる。Fable 5停止の今こそ「Claude 4.8 Sonnet」「Claude Opus 4.8」の使い分けを講義の軸にできる。
- **Web制作**：Claude Code のサブエージェント機能強化で、複数ページの並列コーディングが可能に。案件の開発スピードが2〜3倍に。
- **全事業横断**：輸出規制という前例ができた。マルチモデル戦略（Claude＋GPT＋Gemini 分散）を自社・顧客に推奨する標準方針に格上げすべき。

### 4. Mercury 2（Inception）— 拡散型LLMが1,009トークン/秒を達成。Claude・GPTの5〜10倍速

**要約**
Inception Labsが2026年3月にリリースした Mercury 2 が注目を集め続けている。トークンを1つずつ生成する従来型LLMと異なり、文章全体を並列で拡散的に改善する独自アーキテクチャにより 1,009トークン/秒 を達成（Claude Haiku Reasoning は約89トークン/秒、GPT-5 Miniは約71トークン/秒）。価格は入力$0.25/100万・出力$0.75/100万トークンと低コスト。128Kコンテキスト・ネイティブツール使用・JSON出力に対応。

**重要性**
- **Web制作**：リアルタイムコード生成補助ツールとして Mercury 2 API を組み込むと、顧客へのライブデモの品質が激変する。応答速度が速いためチャットボット系のUXも向上。
- **AI研修**：「LLMの仕組み比較」の研修モジュールに拡散型vs自己回帰型の対比として即採用できる。技術的な差別化説明として分かりやすい事例。
- **補助金支援**：大量文書の高速処理が必要な補助金申請書レビューに低コストで導入できる。
