### 1. Claude Code 2.1.170 正式リリース：ネスト型サブエージェント・Fable 5フル対応

**要約**
Anthropicが6月12日にClaude Code 2.1.170をリリース。最大の新機能は「ネスト型サブエージェント」で、メインエージェントが複数の子エージェントを並列起動し、大規模タスクを分業処理できるようになった。Claude Fable 5への完全対応に加え、プラグイン検索（新UI）・Chrome連携・VSCode/ターミナルワークフローも強化。旧Haiku 4.5がデフォルトのバックグラウンドモデルとして配置され、コスト効率が大幅改善。

**重要性**
- **Web制作事業**：「要件定義エージェント → コーディングエージェント → テストエージェント」を1コマンドで並列起動できる。LP制作の工数をさらに圧縮し、1案件あたりの実作業を1〜2時間に収める現実が近づいた。Cursor併用で最強の制作スタックになる。
- **AI研修事業**：「エージェントにエージェントを使わせる」という次世代AI活用を研修で実演できる。受講者の驚き度が最高クラスで、口コミ効果が高い。研修コンテンツを即刻アップデートする価値あり。
- **補助金支援事業**：補助金申請書の「事業概要 → 技術説明 → 費用対効果」の各セクションを別々のサブエージェントに分担させて並列生成するワークフローを構築できる。申請書作成時間を1/3〜1/4に短縮可能。
