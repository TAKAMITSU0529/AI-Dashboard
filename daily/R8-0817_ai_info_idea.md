### 1. Anthropic：Claude Sonnet 5の価格改定迫る＋Claude Code 50%使用量ブースト延長（8/19まで）

**要約**
Anthropic は Claude Sonnet 5 のプロモーション価格（入力$2/出力$10 per Mトークン）が **2026年9月1日に終了**し、標準価格（$3/$15）へ移行すると正式発表。また Claude Code サブスクライバー向けの50%使用量ブーストを **8月19日まで延長**。さらにComplianceAPIが Claude Code（Web/Mobile/CLI）に拡張され、Enterprise 顧客はセッション内容・メタデータを一元監査できるようになった。

**重要性**
- **AI研修**：9月以降のAPI利用コストが1.5倍になる前に、研修カリキュラム設計・デモ環境の整備を今週中に完了させるべきタイミング。Sonnet 5 を軸にした研修構成をロックする。
- **Web制作**：Claude Code で自動コード生成を行うワークフローを8月中に最大活用し、工数削減の実績データを取得しておく。

### 2. OpenAI：GPT-5.6 Luna/Sol 投入＋週間ユーザー10億人突破

**要約**
OpenAI は ChatGPT の週間ユーザーが **10億人**を突破したと発表。無料・Goユーザーには新モデル **GPT-5.6 Luna** を標準搭載し、Plus/Proユーザーには高速・高精度な **GPT-5.6 Sol** を提供。推論深度を調整できる「Thinkingスライダー」、Google Drive のブラウジング統合、インタラクティブ小テスト機能も追加された。

**重要性**
- **AI研修**：GPT-5.6 を使ったビジネス研修カリキュラム（Google Drive連携によるドキュメント自動分析）は中小企業向けの新コースとして即設計可能。愛知県の製造業・サービス業向けに「AI×業務効率化 半日研修」として売り出す好機。
- **補助金支援**：生成AI（GPT-5.6等）の導入が「デジタル化・AI導入補助金2026」の対象明確化と連動し、AI補助金申請サポートの需要が高まる。

### 3. Google：Gemini 月間10億ユーザー突破＋Gemini 3.6 Flash 登場＋Pixel 11 発表

**要約**
Google の **Gemini アプリが月間10億ユーザー**を達成（Googleの製品史上最速の成長）。8月12日「Made by Google」イベントでは Pixel 11・Pixel Tag（$34の円形トラッカー）を発表し、Gemini Intelligence がカレンダー/マップ/メッセージを横断して次のアクションを自律提案する機能を強化。API では **Gemini 3.6 Flash**（コード・エージェント計画能力向上）と **3.5 Flash-Lite**（低レイテンシ・大量処理向け）をリリース。Granola/Otter.ai/Wix/OpenTable/Ticketmasterなどの外部アプリ連携も拡充。

**重要性**
- **Web制作**：Wixが Gemini 連携を強化しており、AI×Wix のLP制作フロー（ヒアリング→Gemini 自動ドラフト→納品）をパッケージ化すると低単価顧客の高速対応に使える。
- **飲食**：OpenTable との連携強化で、飲食店の予約・混雑管理をGeminiに任せる実証コストが下がった。マーメイドカフェでの試験導入を検討できる。

### 4. OpenClaw：2026.8.1 大型リリース＋Secret Egress セキュリティ強化

**要約**
OpenClaw が **2026.8.1** リリースを展開。主な更新：① Secret Egress Host Binding（クレデンシャルが意図しないホストへ平文送信されるのを防ぐ完全遮断機構）② Sol/Terra/Luna（ChatGPT 5.6系）モデルのフルサポート ③ **ClickClack（Slack代替チャンネル）のガイド付きセットアップ** ④ SQLite スナップショット バックアップ/リストア ⑤ macOSアプリの profile isolation。セキュリティ・信頼性両面での大規模ハード化。

**重要性**
- **AI研修**：OpenClaw は「ローカルAIエージェント基盤」として中小企業向けAI研修の実習教材になる。社内機密データを社外に出さずにエージェントを動かすユースケースを訴求できる（セキュリティ懸念が強い製造業に刺さる）。
- **Web制作・補助金**：Secret Egress Security の強化は、クライアント情報をAIに渡す際のコンプライアンス問題を解決しやすくし、AI活用提案の障壁を下げる。
