### メソッド1：CMOに「知人声かけ」の自動実行権限を付与（Governed Autonomy方式）

- **期待される自律度向上**：「準備→承認待ち→停止」のループを「準備→即実行可能な状態で待機」に変え、社長の意思決定コストを「内容承認」から「送信ボタンを押すだけ」に圧縮。
- **検証方法（明日チェック）**：`outreach/`フォルダに送信用テキストが4名分生成されているか、`growth_log.md`に6/21の実行記録があるか。

## ③ AI Company単独で収益を発生させるアイデア（社長の手を介さない）

### アイデア1：問い合わせ自動応答チャットボット「ミニ診断版」をWebフォーム経由でセルフサーブ化
- **仕組み**：CMOが作成済みの無料AI業務診断（Googleフォーム＋Notion＋Claude）を、見込み客が**自分でURLを開いて回答→AIが自動で簡易診断レポートを即時生成→メール返送**するところまで自動化。社長は商談フェーズのみ介在。
- **想定単価**：診断は無料（リード獲得目的）→ お試し導入パック10〜30万円への転換が収益源
- **立ち上げアクション**：
  1. CPOが既存の診断MVPをWebフォーム化（1日）
  2. CTOがフォーム回答→Claude API→自動レポート生成のスクリプトを実装（2〜3日）
  3. CMOがX投稿・LP経由でフォームへの導線を設計
  4. COOが診断後の商談予約（Calendly等）を自動連携
  5. 1週間テスト運用→車屋以外の見込み客で検証
- **初期投資**：API利用料・フォームツール込みで概算1〜2万円/月

### アイデア2：補助金対象化を活かした「補助金診断ミニツール」をリード獲得ツールとして無料公開
- **仕組み**：COOが「デジタル化・AI導入補助金2026」の対象要件をチェックリスト化し、CTOがWeb上で5問程度に答えると「対象になりそうか／補助額目安」が出る無料診断ツールを作成。結果送付時に補助金支援サービスへの問い合わせ導線を設置。
- **想定単価**：補助金支援1件あたり数万円〜数十万円（成功報酬型）
- **立ち上げアクション**：
  1. COOが対象経費・補助率の要件を整理（1日）
  2. CTOが簡易診断フォームを実装（1〜2日）
  3. CMOがSNS発信でツールを拡散
  4. リード獲得後、社長またはCMOが商談クロージング
- **初期投資**：ほぼゼロ（既存ツールスタックの範囲内）

### アイデア3：占い事業のミニ診断アプリをサブスク化（社長非介在の自動収益）
- **仕組み**：陰陽師・占い事業で、生年月日入力→AI自動鑑定（無料の簡易版）→詳細版は数百円の単発決済またはサブスクで自動課金。Stripe等の決済を組み込めば、鑑定〜課金〜結果送付まで完全自動化可能。
- **想定MRR**：初期は数千円〜数万円規模（低単価×数量型）。TypingMind型「UIで差別化」の発想で体験価値を上げ単価向上を狙う
- **立ち上げアクション**：
  1. CPOが鑑定ロジック＋価格帯（無料/300円/980円サブスク等）を設計
  2. CTOがStripe決済連携＋自動鑑定生成を実装
  3. CMOがSNS発信で無料版から有料誘導の導線を作成
  4. 1ヶ月運用しMRRを実測
- **初期投資**：Stripe手数料のみ（固定費ほぼゼロ）。開発工数がメインコスト

### アイデア4：Mac mini AI役員パッケージの「型」を社内で先に検証し、テンプレ商品化
- **仕組み**：車屋への提案中の「Mac mini + Claude Code + AI役員体制」一式を、自社のセットアップ手順書（②メソッド3）が完成した時点でそのままパッケージ商品の納品マニュアルに転用。CTOが手順書を作る過程そのものが商品開発になる「一石二鳥」設計。
- **想定単価**：50〜300万円（導入パック）＋月5〜30万円（運用支援）
- **立ち上げアクション**：
  1. CTOのセットアップ手順書完成（②と連動）
  2. CPOが手順書をベースに価格・納品物を確定
  3. COOが契約書・NDA雛形を整備
  4. 車屋への提案資料に正式組み込み
- **初期投資**：Mac mini実機検証が必要な場合のみ19〜25万円（顧客への転売前提なら立替）
