## ② AI役員の自律的成長メソッド（今日適用するもの）

### メソッド1：COO・CTOへの「緊急方針アップデート」注入

**対象役員：** COO・CTO
**内容：**
`01_Context_社長の頭の中/今月の最重要テーマ.md` の最終更新日を毎朝チェックし、3日以上更新がない場合にCoSが自動アラートを発する「方針鮮度チェック」を導入する。

**実装：**
```
CoS playbook に追加：
「毎朝 SessionStart 後、今月の最重要テーマ.md の更新日が3日以上古ければ
他役員の growth_log トップに【⚠️ 方針確認待ち】を自動追記する」
```

**期待効果：** 役員が古い前提で動く最大のミス（mistakes.md Case記載）を自律的に防止
**検証指標：** 明日の役員growth_log冒頭に「⚠️ 方針確認待ち」が入っているか

### メソッド2：CMOへの「承認待ちゼロ」プロトコル実装

**対象役員：** CMO
**背景：** 海外事例（BotBorne 2026レポート）によれば、高自律AIエージェントは「人間の承認を待つ」設計を「承認不要タスクへの分離」で解決している。

**内容：**
CMOの業務を「承認不要タスク」と「承認必要タスク」に二分し、承認不要分（SNS下書き・リスト追加・文面候補生成）を即時実行するよう playbook に明記する。

**実装：**
```
CMO playbook に追記：
【承認不要で即実行できるタスク一覧】
- LINE/メール文面の候補生成（2〜3案）
- SNS投稿下書き作成
- 見込み客リストのスプレッドシート追記
- フォローアップスクリプトの更新
【必ず社長確認が必要なタスク】
- 実際の送信・投稿
- 契約・見積の提示
- 単価の変更
```

**期待効果：** CMOの「準備完了待ち時間」をゼロに。社長が承認に使う時間を1日5分以下へ圧縮
**検証指標：** 明日のCMO growth_log で「承認待ちで止まった」記録がゼロか
